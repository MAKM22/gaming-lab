# Gaming Lab

A practical, community-friendly notebook for people who enjoy games, consoles, and experimenting with their gaming setups.

## Topics

- Game guides, reviews, settings, and play notes
- Console setup, accessories, maintenance, and troubleshooting
- Controllers, displays, audio, accessibility, and streaming setups
- PC gaming configuration, performance tuning, and reproducible benchmarks
- Modding and customization, with respect for game licenses, platform rules, and account security
- Small tools and projects that improve the gaming experience

## Tools and projects

- [Simulated PSP telemetry replay](tools/psp_telemetry_replay/README.md): offline
  battery-ID and SYSCON models, power-balance estimates, version-1 JSON inputs
  and golden fixtures, and regression tests. No hardware is accessed; the
  examples do not establish device compatibility, boot success, or causality.

## Sharing a guide

Include the game or hardware model, platform, software/firmware version when relevant, steps to reproduce, and any trade-offs. Label personal opinions and unverified tips clearly. Never include passwords, account tokens, or other private information.

This repository is for lawful, safe learning and sharing. Do not post pirated content, circumvention instructions, or files you do not have permission to distribute.
